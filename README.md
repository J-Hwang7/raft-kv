# raft-kv
Created by Diego Ongaro and John Ousterhout, the Raft Consensus System is a leader-based consensus algorithm that manages replicated logs across servers. While the fault tolerance and performance are comparable to Paxos, Raft utilizes a leader mode that is designed for understandability, unlike Paxos, making it more practical when building systems.
